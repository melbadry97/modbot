# jaw_stock_v1

The unmodified SO-101 gripper jaws, registered as a tool so task packs can name it.

- Files: upstream `STL/SO101/Individual/Moving_Jaw_SO101.stl` plus the fixed jaw built into `Wrist_Roll_Follower_SO101.stl`. No files are stored here.
- Opening width, jaw depth: measure on the first build and record here.
- Padding: none. Add a strip of 1 mm foam or TPU to the tips if socks slip; if you do, register it as `jaw_padded_v1`.
