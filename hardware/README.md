# Hardware

Printable parts that are not part of the upstream SO-101 design. The arms themselves come from [SO-ARM100](https://github.com/TheRobotStudio/SO-ARM100); do not copy its files here, link to a tagged version instead.

Layout: `hardware/<kind>/<name>_v<N>/` with STL files, source CAD when available, and a `README.md` giving what it fits, print settings and measurements.

| Kind | Purpose |
|---|---|
| `tools/` | Jaw sets that replace the stock gripper jaws (interface spec 2.2) |
| `mounts/` | Camera mounts and 4040 feet (spec 2.1, 2.3) |
| `fixtures/` | Trays, zone markers, calibration jigs |
